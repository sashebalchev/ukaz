# T-03 The laws command cannot sign

**Law.** The `laws` command holds no private key and contains no code that reads one or produces a signature.
Signatures come only from the separate signer program, and `laws sign` stores a signature only after verifying it.

**Why.** The command runs where agents run. The key must live somewhere they cannot reach, first behind `sudo` on
the laptop and later on the signing server.

**Blocked.** `laws sign` is run with no signer available: it fails and writes nothing.

**Allowed.** `laws sign` hands the batch to the signer, checks what comes back, and stores it.
