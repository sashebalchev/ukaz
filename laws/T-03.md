# T-03 The laws command cannot sign

**Law.** The `laws` command holds no private key and contains no code that reads one or produces a signature.
Signatures come only from the laptop's fingerprint helper or from the phone, through the signing server, and
`laws sign` stores a signature only after verifying it.

**Why.** The command runs where agents run. The key must live somewhere they cannot reach: on the phone, and
in the helper that only the laptop's root user can read.

**Blocked.** `laws sign` is run with no signing server to ask: it fails and writes nothing.

**Allowed.** `laws sign` posts the batch to the signing server, checks the manifest and the signature that come
back, and stores them.
