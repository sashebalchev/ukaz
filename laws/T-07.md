# T-07 A law without teeth cannot be signed

**Law.** `laws sign` refuses any card above prose grade whose bite is missing or passes. The bite is the card's
blocked case run for real, and it must fail in the way the card says: its output has to contain the text the card
gives as `bite-says`.

**Why.** A check that cannot fail proves nothing, and you should never be asked to approve one.

**Blocked.** A card whose bite command exits 0 is offered for signing. Also blocked: a bite that fails only
because its file name is misspelled.

**Allowed.** A card whose bite command exits 1 is offered for signing.
