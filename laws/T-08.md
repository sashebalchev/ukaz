# T-08 A law can only be removed by you

**Law.** An approved card cannot be removed quietly. `laws verify` and `laws gate` fail when a card named in a
signed manifest is missing, unless a later signed manifest retires it by name.

**Limit.** Deleting a card together with every signed manifest that names it is not noticed by this tool. The
record of approvals has to be kept where agents cannot rewrite it: append-only against the main branch in CI,
and later on the signing server.

**Why.** Deleting a law is the cheapest way around it.

**Blocked.** An approved card's file is deleted, and the gate still answers open.

**Allowed.** You sign the retirement of a card. Its file can then be removed, and the gate stays open.
