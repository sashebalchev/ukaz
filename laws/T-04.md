# T-04 The signer signs only what it computed and showed

**Law.** The signer computes every hash itself from the files, prints the id, title and hash of each card, and
then waits for a person to confirm that list before it signs. It signs exactly that list and appends it to its
log. On the laptop the confirmation is a word typed at a terminal, and with no terminal the signer refuses. It
reads only regular files inside the repository it was given.

**Why.** What you see must be what gets signed, and the signer runs with more rights than the agent that calls it.

**Blocked.** A card lists a frozen file that is a symbolic link to a file outside the repository: the signer
refuses the whole batch. Also blocked: the signer is started by a program that has no terminal, such as an agent's
shell: it refuses and signs nothing.

**Allowed.** Three cards are signed, and the log gains one entry that lists those three.
