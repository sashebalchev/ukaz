# T-09 On the laptop, one touch of the named finger approves one list that waits on the server

**Law.** The laptop's fingerprint helper approves only requests that wait on the signing server. It fetches the
cards of a request from the server itself, at the address in its own settings, and computes every hash from
those bytes. It answers the caller with the list, and only then asks the fingerprint reader for the one finger
named in its settings. If that finger matches within 30 seconds, it writes the list to its log, signs it with
the laptop key and hands the signature to the server. It never signs bytes that a local program hands it.
Another finger, no touch in time, or a call that arrives while one is waiting: nothing is signed. One match
signs one list: no match is kept for a later call.

**Limit.** The laptop's software checks the finger, and the key lies on the laptop's disk where only root can
read it. A program that became root can sign without you. The list is shown by a program that runs as you, on a
screen that programs running as you can draw on. The phone path (T-10) has neither weakness.

**Why.** There is one signing service, on the server. The laptop only adds your finger to it. The network tells
the server that a message came from the laptop, not which program sent it, so "the finger matched" has to be
signed by the helper, with a key that no agent can read. And the helper asks for one named finger only
after the list exists: a login prompt asks before any list exists and accepts any enrolled finger.

**Blocked.** A local program hands the helper cards of its own, which do not wait on the server: nothing is
signed. Also blocked: the reader reports a match for a different finger than the named one. Also blocked:
nobody touches the reader for 30 seconds. Also blocked: a second call while the first one waits for the finger.

**Allowed.** Two cards wait on the server, the named finger touches the reader, and the server then holds one
manifest with one signature that `laws verify` accepts. The helper's log gains one line that lists those two
cards.
