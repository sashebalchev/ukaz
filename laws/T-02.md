# T-02 Approved means signed, by a key you named, over the card as it is now

**Law.** `laws verify` passes only if every card has a signature that verifies against a key in the signers file
and that covers this card's id and its current hash. The signers file is read from outside the repository, never
from inside it.

**Why.** Otherwise an agent could approve a law by adding its own key, or keep an approval alive after changing
the card.

**Blocked.** A key is added to a file inside the repository and a card is signed with it. Also blocked: a
signature made for an earlier version of the card.

**Allowed.** Two cards approved in one batch under one signature.
