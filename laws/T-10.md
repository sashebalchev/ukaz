# T-10 A phone approval is a passkey signature over the exact list

**Law.** `laws verify` accepts an approval made on the phone only if all of this is true: the signature verifies
against a passkey that the signers file lists; it was made over the hash of exactly this manifest; the phone
checked a fingerprint or its screen lock for it; and it was made at the web address that the signers file names
for that passkey. The signers file is read from outside the repository, as in T-02.

**Limit.** The law cannot see where the passkey is kept. If its store is also open on the laptop, a program
there may be able to use it. Keep this passkey in the phone or on a hardware key.

**Why.** The phone's chip releases the key only for your finger, and the signature names the exact list. No
program on the laptop or on the server can make one.

**Blocked.** A real signature from the right passkey is attached to a manifest in which one hash was changed.
Also blocked: a signature that the phone made without checking a finger or the screen lock; a signature made at
another web address; a signature from a passkey that the signers file does not list.

**Allowed.** Three cards approved in one batch on the phone under one signature. Also allowed: a repository
where one manifest was signed with the laptop key and another with the passkey.
